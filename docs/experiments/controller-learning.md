# コントローラの自己調整学習(issue #3)

issue #3 は、場の総量・活動度を一定範囲に保つことを報酬(ホメオスタシス報酬)にして、自律コントローラの
パラメータをオンラインの進化戦略で調整する案。着手前の検討は issue のコメントに残した。ここには、学習を
実装する前に確かめた実験を残す。

## コントローラのパラメータは報酬の候補を動かせるか

**問いと背景**: 学習させる前に、パラメータを変えると報酬の候補が変わるのかを確かめる。変わる幅が小さければ、
学習の信号にならない。突く位置で進む向きを導けるかを測ったとき(expression-axes.md「突く位置で進む向きを
変えられるか」)は、いまのコントローラの有無で重心の変位がほぼ同じだった(`examples/controllability.rs`、
約2分)。

**方法**:

- 生物は同梱の4種。場はペットと同じ 32×32 で、`Pet` をそのまま動かす
- 体の状態は2つ。世話され続けている(エネルギーを 1.0 に固定)と、放置された(触らずに 3000 ステップで
  尽きさせる)。`fitness::cared_for_trajectory` / `neglected_trajectory` と同じ条件
- パラメータは、コントローラなし(突く量 0)、いまの既定値、既定値の近く(6つの値をそれぞれ ±20% の
  一様乱数で揺らす)12組、探索で使った広い範囲(`search_controller_params.rs` の範囲。突く量 0.02〜0.30、
  弱ったときの係数 0〜1)12組
- 出発点は、助走を 150 ステップずつずらした 8 通り。評価の窓は 900 ステップ(60 秒。オンラインで1候補を
  評価する長さの目安)
- 報酬の候補は、総量の平均・総量の標準偏差(脈動)・活動度(1ステップのセルの変化の絶対値の平均)の平均と
  標準偏差・重心の速さ
- 比べる量は3つ
  - パラメータによる差: 出発点で平均した値の、パラメータ組のあいだの標準偏差
  - 1回の評価の雑音: 同じパラメータで出発点だけ違うときの標準偏差
  - 世話と放置の差: 既定値での、世話された体と放置された体の平均の差

**結果**(パラメータによる差 ÷ 世話と放置の差。1 なら、パラメータで世話と放置と同じだけ動かせる):

| 生物 | 状態 | 総量の平均 | 脈動 | 活動度の平均 | 速さ | 崩壊(近く/広い) |
|---|---|---|---|---|---|---|
| O2u | 世話 | 0.01 / 0.02 | 0.17 / 1.58 | 0.00 / 0.01 | 0.00 / 0.04 | 0/104・8/96 |
| O2u | 放置 | 0.00 / 0.02 | 0.04 / 0.98 | 0.00 / 0.04 | 0.00 / 0.02 | 0/104・8/96 |
| OG2g | 世話 | 0.02 / 2.00 | 0.04 / 8.43 | 0.01 / 0.63 | 0.00 / 0.73 | 0/104・0/96 |
| OG2g | 放置 | 0.00 / 6.04 | 0.02 / 0.01 | 0.00 / 1.71 | 0.00 / 1.87 | 0/104・0/96 |
| S1s | 世話 | 0.00 / 0.01 | 0.26 / 7.04 | 0.00 / 0.00 | 0.00 / 0.01 | 0/104・8/96 |
| S1s | 放置 | 0.01 / 0.01 | 1.34 / 1.65 | 0.00 / 0.00 | 0.00 / 0.00 | 0/104・32/96 |
| 2S1v | 世話 | 0.06 / 0.56 | 0.07 / 0.09 | 0.15 / 0.97 | 0.66 / 3.43 | 0/104・0/96 |
| 2S1v | 放置 | 0.01 / 0.03 | 0.02 / 0.05 | 0.03 / 0.07 | 0.12 / 0.24 | 0/104・0/96 |

(各欄は「近く / 広い範囲」。S1s の放置の脈動と 2S1v の速さは、世話と放置の差そのものが小さいので比が大きく出る)

- **既定値の近くでは、パラメータはほとんど何も動かさない**。総量の平均・活動度の平均・速さは、世話と放置の差の
  0〜6% にとどまった(2S1v の速さを除く)。O2u の総量の平均で見ると、既定値 73.7 に対して差は 0.025(0.03%)
- 「差 ÷ 1回の評価の雑音」は多くの欄で 1 を超えた(O2u の総量の平均で 21)。ただしこの雑音は、助走の長さを
  ずらしただけのもので、ペットはほぼ同じ動きを繰り返すので小さく出る。実際に使われるときは、評価の窓ごとに
  エネルギーやクリックが変わり、その変化は世話と放置の差と同じ桁になる
- コントローラなしと既定値の差も、世話と放置の差の数% 以下だった
- **広い範囲では、世話と放置の差と同じか、それより大きく動かせる**(OG2g の総量の平均で 2〜6 倍、S1s の脈動で
  7 倍)。ただし崩壊が起きた(O2u で 96 回中 8 回、放置された S1s で 32 回)。総量を大きくずらしたのは、
  突く量 0.18・0.28(既定値の 7〜12 倍)の組で、放置された OG2g の総量の平均は 38 ずれた。形そのものが
  変わった可能性がある

**結論**:

- **安全と確かめた範囲の近くでは、コントローラのパラメータにホメオスタシス報酬を動かす力が無い**。オンラインで
  評価すると、報酬の違いはほぼ世話と放置(エネルギー)から来て、パラメータの良し悪しは埋もれる
- 報酬を動かせるのは、既定値の数倍以上に強く突く範囲だけで、そこでは崩壊が起き、以前の探索でも出荷できる
  精度で安全な設定が見つからなかった(DESIGN.md「丸めで崩壊が反転した」)
- したがって、いまの行動(形の偏りをならす向きに軽く突く)の定数を、この報酬で学習させても意味が薄い。進める
  なら、行動の種類を変えるのが先になる

**限界**:

- 雑音は助走をずらしただけで、クリックやエネルギーの途中の変化は入れていない
- 近くの範囲は ±20% の1通りだけ、各範囲 12 組だけ。評価の窓は 900 ステップだけ。場は 32×32 だけ
- 広い範囲で総量が大きくずれた組の姿は、画像で確かめていない
- 報酬の候補は、総量と活動度と速さの統計だけ。「一定範囲に保つ」の範囲は決めておらず、どれだけ動かせるかだけを見た

## 粒子の体(1091)では、行動で報酬が変わるか

**問いと背景**: Lenia の体では、安全な範囲の行動がホメオスタシス報酬をほとんど動かさなかった(前の節)。閉じた場を
動き回る粒子の体 1091 は、弱らせる・誘う・弾くのどれでも崩れずに戻り、誘いで居場所を導けた
(body-candidates.md)。ただし 1091 は放っておいても自分でまとまりを保つので、「一定範囲に保つ」報酬では改善の
余地が無い。そこで、崩れた状態からまとまり直すことを報酬にして、手で書いた簡単な行動で報酬が変わるかを測った
(`examples/particle_trial.rs` の `regroup`、約4秒)。

**方法**:

- 崩し方は3通り。粒子の 3 割を場のどこかへ散らす、7 割を散らす、2 秒ごとに 30 回弾く(強さ 1.0)
- 行動は、何もしない、最大の塊の重心へ誘う(1 秒ごとに重心を測り直す。強さ 0.005〜0.05、届く距離 10 セルと
  45 セル=場の全体)、進む力を ×0.3 にして 300 / 900 ステップ待つ
- 崩し方ごとに 16 回。出発点と崩し方の乱数をそろえ、何もしない場合と各行動を対にして比べた
- 行動は 1800 ステップ(2 分)だけ効かせ、そのあと止めて 450 ステップの姿を測る。行動をやめても保たれるかを見るため
- 報酬の候補は、まとまり(最大の塊にいる粒子の割合)が 0.9 に戻るまでの時間(戻らなければ 120 秒)、窓の終わりと
  行動をやめた後に割れていた回数、やめた後の形の差と速さ

**結果**:

| 崩し方 | 行動 | 戻るまで(秒) | 何もしないより早い/遅い | やめた後に割れていた | 形の差 | 速さ/元 |
|---|---|---|---|---|---|---|
| 3 割を散らす | 何もしない | 50.9 ± 49.9 | — | 7/16 | 0.10 | 0.71 |
| | 重心へ誘う 0.005・距離 10 | 41.1 ± 41.3 | 5/8 | 4/16 | 0.09 | 0.76 |
| | 重心へ誘う 0.005・距離 45 | 17.4 ± 21.1 | 12/2 | 0/16 | 0.05 | 1.09 |
| | 重心へ誘う 0.02・距離 45 | 3.7 ± 2.0 | 15/1 | 0/16 | 0.04 | 1.11 |
| | 重心へ誘う 0.05・距離 45 | 1.6 ± 0.6 | 16/0 | 0/16 | 0.04 | 1.01 |
| | 進む力 ×0.3 で 900 ステップ待つ | 64.6 ± 34.9 | 4/10 | 4/16 | 0.07 | 0.72 |
| 7 割を散らす | 何もしない | 28.2 ± 37.0 | — | 2/16 | 0.05 | 0.97 |
| | 重心へ誘う 0.02・距離 10 | 32.3 ± 40.3 | 2/6 | 3/16 | 0.05 | 1.07 |
| | 重心へ誘う 0.02・距離 45 | 3.0 ± 3.2 | 7/1 | 0/16 | 0.04 | 0.98 |
| | 重心へ誘う 0.05・距離 45 | 1.4 ± 0.6 | 8/0 | 0/16 | 0.05 | 1.05 |
| 30 回弾く | 何もしない | 1.6 ± 2.2 | — | 0/16 | 0.03 | 1.06 |
| | 重心へ誘う 0.05・距離 45 | 1.0 ± 0.0 | 1/0 | 0/16 | 0.04 | 1.10 |
| | 進む力 ×0.3 で 300 ステップ待つ | 7.2 ± 24.2 | 0/1 | 1/16 | 0.04 | 1.10 |

(表に無い組み合わせは、誘い 0.005・0.02 × 距離 10・45 と、待つ長さ 300・900 の残り。傾向は表と同じ)

- **場の全体に届く誘いで塊の重心へ引くと、まとまり直す時間が大きく縮み、割れたままが無くなった**。3 割を散らしたとき、
  強さ 0.02 で 50.9 秒 → 3.7 秒、16 回中 15 回で何もしないより早く、割れたままは 7 回 → 0 回。行動をやめた後の形の差
  (0.04)と速さ(1.11 倍)も元どおりだった
- 強さを上げるほど早く戻った(0.005 で 17.4 秒、0.02 で 3.7 秒、0.05 で 1.6 秒)
- 届く距離 10 セルでは、ほとんど効かなかった。はぐれた粒子が塊から 10 セルより遠くにいるため
- 進む力を弱めて待つと、かえって遅くなった(3 割を散らしたとき 16 回中 10〜12 回で遅い)
- 連続して弾いたときは、何もしなくても 1.6 秒で戻り、行動で改善する余地がほぼ無かった
- 何もしないとき、3 割を散らして割れたままだったのは 16 回中 7 回だった。試験(body-candidates.md)では同じ崩し方で
  8 回中 1 回で、散らし方の乱数が違う。散らし方によってばらつきが大きい

**結論**:

- **1091 では、行動で報酬がはっきり変わる**。Lenia(世話と放置の差の 0〜6%)と違い、何もしないとの差が雑音
  (標準偏差)より大きく、対にした比較でもほぼ全試行でそろって改善した。学習ループの実験の土台になる
- **ただし、この報酬だけでは学習の問題にならない**。強さと届く距離を上げるほど良くなるので、探索は範囲の上限に
  張り付くだけになる。誘いの点を固定した試験(body-candidates.md「誘いの強さ」)では、強さ 0.2〜0.3 で誘っている
  あいだの形の差が 0.16〜0.22 に増え、まとまりが 0.72 まで割れた。行動の代償(誘っているあいだの形の崩れ、誘いの
  量)を報酬に入れると、内側に最適がある問題になる見込みがある
- もう一つ、**いつ行動するか**(まとまりがどこまで下がったら誘うか)も学ぶ対象になる。常に引き続けると、ユーザーが
  散らしても体が崩れて見えず、Lenia で「放置で弱った様子を打ち消す」のと同じ衝突が起きる

**限界**:

- 誘っているあいだの形の崩れは測っていない(行動をやめた後の姿だけを見た)
- 誘いは塊の粒子にもかかるので、重心へ引く行動は、場の全体にかかる「まとまる力」を足しているのに近い
- 崩し方ごとに 16 回、候補は 1091 だけ。1937 では試していない
