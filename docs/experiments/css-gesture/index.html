css-gesture spike — 決定モデルの出力が「読める動き」になるか

左が clef の結果。右に laya を並べた。 判定したいのは4点: ①8個のジェスチャーが読み分けられるか ②分布の混合が意味のある中間になるか ③confidence が低いとき「迷い」に見えるか ④ score 軸が動きの差として知覚できるか。
θ（emit の発火しきい値）= 0.30 を使っている。素直に 0.5 にすると Clef は 8件すべてが idle になった（明確な場面でも emit は 0.49 止まり）。しきい値は推測せずデータから決める必要がある、 という較正の実測例。emit < θ の件は idle に落とし、モデルが選んだジェスチャーは括弧内に残した。
