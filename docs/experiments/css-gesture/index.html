css-gesture spike — 姿勢パラメータ空間（混合は補間、描画は1体）

語彙を poses.json の{amp_x, amp_y, lift, sink, size, freq, flick} の点として定義し直した。 混合は重み付き平均（補間）で1つの姿勢ベクトルにし、描画は常に1体。
lift / sink は上下の向きを分けた非負のチャネル。静的な偏りは (sink - lift) が担い、 符号付き平均が捨てていた 2*min(lift, sink) を縦の揺れとして戻すので、 「沈む + 浮く」が中立ではなく葛藤（揺れ）として描かれる（各カードの「葛藤」の値）。
前版の「確率で重ねる」方式は半透明の図形がずれた雲になり、動きの混合にならなかった（人の判定）。 表示を切り替えると、一番確率の高い姿勢（argmax）と、補間した姿勢（mean）を同じ枠で比べられる。
モデル clef / 比較 laya。 波の形は往復の正弦1種類に統一したので、perk_up の「一瞬沈んでから跳ねる」ような 波形の違いは表現できない（振幅・速度・静的偏りで近似）。
