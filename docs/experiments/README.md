# 実験の記録

ペット本体の設計を変えなかった実験を、テーマごとに残している。いまの設計と、その根拠になった判断は
[docs/DESIGN.md](../DESIGN.md) にあり、設計に効いた結論だけは docs/DESIGN.md「実験から分かったこと」
にも書いてある。

- 各節は、おおむね「問いと背景 → 方法・条件 → 結果 → 結論 → 限界」の順で書いてある。結論だけ知りたい
  ときは、下の表から読む
- 実験の道具は `crates/vmc-pet-body/examples/` にあり、各節に使ったツールの名前を書いてある
- コードのコメントは `docs/experiments/<ファイル>「節の名前」` の形で節を参照している

## [崩壊の先読みと、場を使った予測](collapse-prediction.md)

| 節 | 問い | 結論 | 設計への影響 |
|---|---|---|---|
| 崩壊を見える量から先読みできるか(小さなモデル) | 総量や密度など見える量から、崩壊を先読みできるか | 見える量が崩れるのは崩壊の 0.3 秒ほど前から。誤警報を出さない条件では、総量のしきい値と変わらない | パラメータを崖から離しておく方針を裏づけた |
| 崩壊を場から先読みできるか(場を読むモデル) | 場そのものを読めば、早く気づけるか | 崩壊の1秒前後の直前には情報があるが、見ていない負荷や生物には移らない | なし |
| パラメータと場の両方から崩壊の確率を当てる | パラメータが分かっているとき、場を足すと崩壊の確率がよく当たるか | O2u・OG2g・2S1v では当たらない。S1s は、安全な範囲の中でも急な切り替えで崩壊しやすい | 安全な範囲は生物ごとの固定パラメータで守る。S1s の急な切り替えは DESIGN.md 第3部の未確定事項 |
| Lenia の場をリザバーとして使えるか | 場を計算資源(リザバー)として使えるか | 生物がいると場に記憶が生まれる(空の場は0)が、一番良い O2u でも同じ大きさの ESN の約3分の1 | なし |

## [体の規則の候補(issue #1)](rule-candidates.md)

| 節 | 問い | 結論 | 設計への影響 |
|---|---|---|---|
| 成長の強さの崖は時間の刻みから来ているか | 時間を連続に近づければ、崩壊の崖はなだらかになるか | ならない。崖の位置は刻みで動くが消えず、O2u では刻みを細かくするほど崖が上がる | 規則の候補は、崖の位置と余裕、既存の生物が生きられるかで比べる |
| 放置されてがっかりした体の余裕 | 放置されてがっかりした体は、崩壊までどれだけ余裕があるか | 徐々に弱らせるなら十分(テンポ ×0.6 の O2u で崖は 0.80〜0.77)。全4種のペットも16回とも崩壊しなかった | 下限 0.85 とテンポ ×0.6 を据え置き |
| Asymptotic Lenia で既存の生物は生きられるか | 規則を差し替えるだけで使えるか | 使えない。既存の生物は総量が 9〜12 倍に膨らむか、崩壊するか、動かない塊になる | 採らない。`Lenia::step_asymptotic` を実験用に残す |
| SmoothLife を軽く動かしてみた | 見た目の違う規則を確かめる | グライダーは 128×128・外側の半径 21 のときだけ現れ、ペットの場には収まらない | 採らない |
| Glaberish を取り込む | 式を取り込んで、既存の生物がそのまま使えるか | 4種とも崩壊せず動く(軌跡は途中から分かれる)。yuca の s613 のカエルも再現した | `Lenia::step_glaberish` を実験用に取り込んだ。ペットは使っていない |
| 多チャンネル Lenia の計算の重さ | 多チャンネルは、負荷の面でましか | 計算はカーネル本数にほぼ比例する(2本で約2倍、15本で約15倍)。M5Stack ではどの構成も目標に収まらない | なし |
| 多チャンネル Lenia の生物を動かす | 一次資料の多チャンネルの生物を Rust で動かせるか。ペットの場でも生きるか | 移植は参照実装と5〜6桁で一致。形を保つのは元の大きさで 72 体中 38 体、R 13・64×64 で 32 体、ペットの 32×32 で 21 体(動くのは2体) | なし。載せるなら場を 64×64 程度に広げる必要がある |
| 多チャンネルの生物をペットの試験にかける | 64×64・R 13 で形を保った生物は、ペットが与える変化で崩壊せず戻れるか。チャンネルの配分は表情の軸になるか | 32 体中 9 体が合格し、弱ると見た目の差が 0.5 を超える体もあった。ただし 23 体中 18 体は弱ると崩壊した。1つのチャンネルだけ弱らせても色の割合はほとんど変わらない | なし。色の配分は表情の軸にならない |

## [表現軸を広げる実験](expression-axes.md)

| 節 | 問い | 結論 | 設計への影響 |
|---|---|---|---|
| 生き残る関数で表情を足せるか | 活発さとは質の違う見た目を、崩壊させず、戻せる形で作れるか | 戻れる変化は脈動の強弱だけ。質の違う形(ドーナツ形・歯車形)は一方通行 | 表現軸は増やさない |
| 別の形から戻る帰り道はあるか | 止まった形から、逆向きのきっかけや、ほかの状態・生物の値を経由して戻れるか | 戻れなかった | 形の移り変わりは一方通行として扱う |
| 滑る S1s は谷の狭い形か | 滑る形と止まった形は、どんな初期状態から現れるか | S1s に近い形以外はすぐ崩壊した。ドーナツ形は S1s 以外の初期状態 368 回のうち1回だけ | なし |
| 柔軟な生物を探す | 変形しても死なず、元に戻り、見た目の幅が大きい体を探す | 成長関数の中心と幅の格子には、既存の生物より大きく柔軟な体は無かった。見た目の幅が大きい候補ほど戻れない | 探索を続けるなら、評価(止まった体の扱い)と探す範囲(カーネル)の見直しが要る |
